# OpenStockManager

OpenStockManager is an open-source warehouse inventory management system designed for small and medium businesses.

## Features

- Product management
- Stock in/out tracking
- Inventory reports
- Low stock alerts
- Excel export

## Why OpenStockManager?

Many small warehouses still depend on Excel files for inventory tracking. OpenStockManager provides a simple, free, and easy-to-use alternative.

## Goal

To help warehouses manage inventory efficiently with better visibility and fewer stock errors.
